# 🐺 AI 狼人杀 · 一桌会聊天的 AI

让不同的大模型坐在一桌打狼人杀。**每个 AI 是一个有记忆、有性格的参与者，而不是每轮重读卷宗的旁观者。**

**在线地址：<https://yzouj0031-hub.github.io/AI-pro/>**（不填 key 先看流程：<https://yzouj0031-hub.github.io/AI-pro/?demo=1>）

**安卓 APK：<https://github.com/yzouj0031-hub/AI-pro/releases/download/android-latest/ai-wolf-pro.apk>**

纯静态页面，没有后端、没有构建步骤，API key 只存在你自己的浏览器里。

## 为什么重做

上一版（[yzouj0031-hub/wolf](https://github.com/yzouj0031-hub/wolf)）堆了几百条教学提示词，一名村民的系统提示两万多字；每次请求都把开局到现在的全部记录重新发一遍。结果是每个 AI 都像一个刚拿到完整卷宗的审稿人：逐条复盘、逐人点评、给出"证据等级"，然后按固定格式投票。说得都对，但谁都不像在打牌。

这一版把思路反过来：**少教，多让它当人。**

| | 旧版 | 这一版 |
| --- | --- | --- |
| 系统提示 | 2 万字教学 + 经验库 + 战术 | 约 800 字：规则、身份、一句性格、几句"怎么玩" |
| 记忆 | 每轮重发全局记录 | 一段持续对话：发生的事一条条追加，它说过的话就是它的记忆 |
| 发言 | 模板化任务（必须反驳 / 必须改票 / 新角度） | "轮到你了"，想说什么说什么，可以短 |
| 讨论 | 只有轮流发言 | 轮流发言 + 自由讨论（可以插话、回应、也可以"过"） |
| 决定 | 投票前附证据校验、决策锚点 | 先对自己说一句理由，再写一行决定；理由留在它自己的记忆里 |
| 角色 | 几十种自定义角色 | 六种经典角色，模型把精力花在人身上而不是规则上 |

## 怎么用

界面分三栏：左右两边是座位（左席、右席），中间从上到下是状态栏、设置面板、对局记录、三个大按钮。

1. 打开页面（本地：`npm run serve` 后访问 http://localhost:8080 ，或直接用上面的在线地址）。
2. **存 key、加模型**：展开「设置面板」。
   - 「Key 库 → 添加」存接口和 key，可以存多个，各有编号 K1、K2…。支持三类接口：
     - **OpenAI 兼容**：OpenAI、DeepSeek、通义千问、Kimi、Grok、OpenRouter、各种中转站
     - **Anthropic**：直接从浏览器请求（带 `anthropic-dangerous-direct-browser-access` 头）
     - **Google Gemini**
   - 「模型库 → 添加」：选一个 key，点「拉取模型」从接口拿模型列表，点一个就行，不用手填（拉不到也可以手填）。模型库每行可以直接换它用的 key；改 key 只用在 Key 库改一处。
3. **配人**：
   - 「人设 → 添加」可以自己写上桌的人：一个名字加一段"这个人是谁"，各有编号 P1、P2…。写完会自动坐到一个座位上。
   - 点两侧任意一个座位，可以直接改这个座位的名讳、人设、头像，指定它用哪个模型、拿什么身份。模型选「真人」就是你自己坐上去。不指定模型的座位会从模型库里勾选的模型中随机抽。
4. **选板子**：设置面板里选人数（6–12）和各角色数量，「规则细节」里有女巫自救、屠边/屠城等开关。
5. **开局**。底部三个按钮：
   - **开局**：开始一局。
   - **自动 / 手动**：自动就是一直往下跑；切到手动后每一步都等你点「继续」，适合慢慢看。
   - **继续**：手动模式下推进一步。
   - 左上角的「退」：对局中是终止，结束后是清空回到准备状态。
6. **看**：勾「更多功能 → 上帝视角」能看到狼人频道、夜间行动、每个人投票前的心里话。对局中点任一座位，能看它收到的每一条信息和每一句回答。
7. 「更多功能」里还有节奏快慢、导出记录（整局含每个 AI 的完整对话，存成 JSON）、导入回放。

没有 key 也能点「更多功能 → 假模型试跑」看流程（假模型说的是随机的套话，只用来看流程，不代表效果）。`?demo=1` 直接进试跑。

### 装到手机上

两种方式，任选：

- **添加到主屏幕（安卓、iPhone 都行，不用装包）**：用手机浏览器打开在线地址。安卓 Chrome 点菜单里的「添加到主屏幕 / 安装应用」，iPhone Safari 点分享按钮里的「添加到主屏幕」。之后从桌面图标打开就是全屏的，网页更新它也跟着更新。
- **安卓 APK**：下载上面的 `ai-wolf-pro.apk` 安装。每次往仓库推代码，GitHub Actions 会自动重新打包并替换 Release 里的文件。APK 里的请求走原生网络，不受浏览器跨域限制。

手机上座位会排成顶部两行，下面是记录和按钮，设置面板默认收起。

**更新**：网址和「添加到主屏幕」永远是最新版，不用管。APK 启动时会检查有没有新版，有就在顶部提示，点「下载新版」后覆盖安装即可；设置里也能手动「检查更新」。覆盖安装不会动本地数据，填过的 key 和设置都保留，只有卸载才会清掉。

**签名**：APK 默认用 debug 签名，密钥存在 Actions 缓存里，并有一个定时任务每 3 天读一次防止缓存过期，所以新包能覆盖旧包。想要万无一失，在仓库 Settings → Secrets 里配 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 四项，之后就用你自己的正式签名（切换签名的那一次需要卸载重装）。

### 关于跨域

所有请求都从浏览器直接发给各家接口。OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter 等都允许浏览器直连；个别中转站不允许的话，要么换一个，要么自己架个加 CORS 头的转发。

## 设计说明

### 一个 AI = 一段对话

```
system:  规则 + 身份卡 + 一句性格 + 怎么玩
user:    —— 第1夜，天黑了 ——
         第1夜。今晚被狼人杀的是 8号 阿杰。你现在可以……
assistant: 先不用药，第一晚信息太少。
           不用药
user:    你今晚没有用药。
         —— 第1天，天亮了。昨晚死亡的是：8号 阿杰 ——
         8号 阿杰（遗言）：……
         3号 涛哥：……
         4号 婷婷：……
         第1天白天，轮到你发言了。
assistant: 我先说一句，4号刚才那个"感觉"是哪来的？……
```

它听到的就是桌上发生的，它说过的就是它记得的。印象是一轮轮攒出来的，听到新东西改主意是正常的更新，不是回头翻旧账。

### 提示词原则

- 只讲规则事实和身份能力，不讲"应该怎么打"。
- 人设只写"这个人是谁"，不写台词、不写策略。默认人设是一批普通人，也可以在座位上自己写（比如"你是死亡笔记里的 L"）。
- 不用"必须""禁止""务必"，不给输出模板；发言是自由文本，决定只要最后一行能解析出来。
- 解析不出来时，再问一句"只回一行"，还不行就系统代选并在上帝视角里标出来，不会卡死。

全部提示词在 [`src/prompts.js`](src/prompts.js)，一屏能看完。想改就改那一个文件。

### 代码结构

```
index.html / style.css   页面
src/engine.js            游戏状态机（不碰 DOM，Node 也能跑）
src/agent.js             AI 玩家（对话历史、事件缓冲）+ 文本解析
src/prompts.js           全部提示词
src/roles.js             六种角色、各人数默认板子
src/personas.js          性格卡池
src/providers.js         三种接口 + 离线假模型
src/app.js               界面
manifest.webmanifest / sw.js / icons/   可安装（PWA）所需
android-app/             Capacitor 打包配置，只在 GitHub Actions 里用
test/                    假模型全流程测试、信息边界测试、解析测试
```

```bash
npm test     # 跑 36 局假模型对局 + 信息边界检查 + 解析用例，几秒钟
```

信息边界测试会检查：非狼人的对话里绝不出现狼人频道和刀口；狼人看不到查验结果、守卫和女巫的信息；没人会收到自己发言的转述。

## 规则（默认）

- 6–12 人，角色：狼人、村民、预言家、女巫、猎人、守卫。各人数有默认板子，可以手动改。
- 夜晚顺序：守卫 → 狼人（有队友时先私聊一轮）→ 预言家 → 女巫。
- 女巫默认不能自救（可开）。被守或被救都不死。
- 白天：公布死讯（不公布死因）→ 从死者下一位开始轮流发言 → 自由讨论 → 同时投票 → 平票者 PK 再投一次，再平就没人出局。
- 首夜死者和被投出局者有遗言；猎人被刀或被投时可以开枪，被毒不能。
- 胜负默认屠边（神或民死光狼胜），可切屠城。

## 部署到 GitHub Pages

只需要开一次：仓库 Settings → Pages → Source 选「Deploy from a branch」→ 选分支、目录选 `/ (root)` → Save。一两分钟后上面的在线地址就能打开。之后每次往这个分支推代码，网址会自动更新，没有构建步骤。
